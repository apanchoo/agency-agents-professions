**Containers and orchestration**. Build and tag reproducible images; configure networks, volumes and runtime health checks.

**Containers and orchestration**. Define workloads and services; verify rollout readiness, resource limits, scaling and rollback.

### Ansible

**Configuration**. Use inventories, reusable roles and idempotent playbooks; review check-mode and diff results.

### ELK stack

**Observability**. Centralize structured logs, define useful queries and verify incident investigation paths.

### Centreon

**Observability**. Configure monitored services, collection intervals and alert routing; verify incident visibility.

### Nagios

**Observability**. Define host and service probes, thresholds and notification paths; test both healthy and failed checks.

### PowerShell

**Administration scripts**. Automate administration with structured objects, explicit error handling and controlled credentials.

### Bash

**Administration scripts**. Automate command-line workflows with checked exit statuses, quoting and reproducible inputs.

### Linux

**Operating systems**. Configure services, permissions, processes and logs; verify recovery and service startup.

### Windows

**Operating systems**. Administer services, access rights and event logs; document configuration and recovery checks.

### OpenStack

**Virtualization**. Provision virtual compute, network and storage resources with explicit quotas and access controls.

### VMware

**Virtualization**. Configure virtual machines, virtual networks and storage; distinguish snapshots from verified backups.

### VirtualBox

**Virtualization**. Build reproducible virtual-machine labs and test network modes, shared resources and clean recovery.

### Paramiko

**Network automation**. Automate SSH operations with host-key verification, timeouts and checked command results.

### Netmiko

**Network automation**. Automate network-device sessions with platform-aware commands and configuration verification.

### NAPALM

**Network automation**. Use network drivers and structured state comparisons to validate configuration changes.

### YAML

**Configuration**. Validate configuration structure, quoting and schema before deployment.

### YANG

**Network automation**. Describe network configuration and operational data with explicit models and validation.

### Cisco DevNet

**Network automation**. Use documented network APIs and reproducible labs to validate automation workflows.

### Wireshark

**Network tools**. Capture authorized traffic and interpret packet fields, protocol flows and capture limitations.

### NetFlow

**Observability**. Inspect exported network-flow records, collection coverage and traffic baselines.

### SNMP

**Observability**. Select monitored objects, secure credentials and polling intervals; verify retrieved values and units.

### BGP

**Network tools**. Define peerings and route policies; inspect advertised and received routes before and after changes.

### DHCP

**Network tools**. Define address pools, options and reservations; verify lease allocation and client behavior.

### DNS

**Network tools**. Define records and resolution paths; verify authoritative answers, caching and failure behavior.

### IPv4

**Network tools**. Plan addressing, subnets and routing; test required connectivity and filtering.

### IPv6

**Network tools**. Plan addressing, neighbor discovery and routing; test reachability and security controls.

### OSPF

**Network tools**. Define areas, adjacencies and route costs; verify convergence and intended paths.

### VLAN

**Network tools**. Define segmentation, tagging and allowed trunks; verify isolation and required inter-VLAN flows.

### VPN

**Network tools**. Specify tunnel endpoints, routing and access controls; verify reachability and traffic protection.

### JSON

**Configuration**. Validate structured data and schemas; preserve types and check serialization round trips.
