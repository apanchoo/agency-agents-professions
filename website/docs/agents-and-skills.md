# From a role to a useful result

An **agent** defines a professional perspective: its scope, working style, priorities, workflow and expected outputs. A **skill** explains how to perform work within that scope and provides references to load when needed.

## A complete profession package

Each profession includes an agent profile, a `SKILL.md`, detailed expertise and practical validation scenarios. Copy the entire skill folder to retain its references.

Native profession files are standalone. Their expertise is embedded so upstream converters can generate portable integrations without breaking relative links.

## Boundaries

Agents do not acquire real-world credentials by adopting a role. They must distinguish analysis, simulated results, planned interventions and physical work actually performed by a qualified person.
