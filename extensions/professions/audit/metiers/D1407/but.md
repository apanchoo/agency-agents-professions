# Enrichissement BUT et preuves

Les rapprochements et la sélection des fiches pédagogiques sont produits par le générateur et restent à relire. Un code cité dans un programme atteste cette mention, sans prouver une équivalence diplôme/métier. Un code parent est distingué d'un code exact. Les pages sont les pages physiques du PDF, base 1. Le texte des pages est une extraction ; les tableaux peuvent perdre leur disposition.

> à travers une étude de cas ou un simulateur de gestion. La démarche consiste à explorer :
> – L ’image de l’entreprise et son positionnement
> – Les aspects budgétaire liés à la trésorerie
> – L ’étude concurrentielle
> La démarche devra permettre d’utiliser des outils de curation de contenu afin d’atteindre les objectifs fixés.
> Apprentissages critiques :
> – AC12.01 | Caractériser les différentes fonctions de l’organisation
> – AC12.02 | Identifier l’environnement juridique de l’organisation
> – AC12.03 | Identifier les enjeux humains du pilotage de l’organisation
> – AC12.04 | Identifier les indicateurs fondamentaux utiles pour le pilotage interne
> – AC12.05 | Positionner l’organisation dans son environnement économique
> – AC12.06 | Produire une information pertinente pour le pilotage de l’organisation
> Ressources mobilisées et combinées :
