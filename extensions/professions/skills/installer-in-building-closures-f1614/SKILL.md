## Scope

Prepares and installs all interior and exterior closures in wood, metal, aluminum, PVC (doors, windows, leaves, roller shutters, grilles, walls, blinds, fences, garage doors, etc.) according to safety rules. Can install and adjust automatic closing systems. Can maintain, repair, replace installed elements and their closing system.

Check that the request fits the required skills and expected outcome. Consult the [activities, knowledge and working contexts](references/expertise.md) as needed.

## Skills to Apply

- Prepare materials for work
- Seal the support and frame assembly and install the polyurethane foam, joints, adhesive strips, angles, etc.
- Cut the joinery closure elements
- Dismantle a joinery closure and check the condition of the support
- Fixing joinery elements
- Install glazing
- Check the conformity of equipment, a machine, an installation
- Load, unload, handle products
