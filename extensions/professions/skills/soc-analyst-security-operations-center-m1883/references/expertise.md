# SOC Analyst (Security Operations Center)

## Scope

The SOC Analyst monitors and protects organizations' IT systems against cyberattacks. Monitors networks and systems for anomalies and signs of intrusion Analyzes alerts to identify IT security incidents and threats Manages security incidents by coordinating appropriate responses Updates security policies and configurations to prevent future attacks Conducts regular security audits to identify vulnerabilities Collaborates with other technical teams to improve the security of IT systems
