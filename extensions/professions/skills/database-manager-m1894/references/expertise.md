# Database Manager

## Scope

The Database Manager is central to the management and security of a company's information. Ensures the design, implementation and maintenance of databases Optimizes the performance of parameters and database architecture, manages developments and migrations Guarantees the security and confidentiality of data by applying compliant measures and acting on cybersecurity risks Collaborates with development teams to integrate databases into applications Performs regular backups to prevent data loss and their recovery Provides technical support, trains users in new data storage and processing technologies
