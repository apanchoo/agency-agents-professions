# Pattern maker

## Scope

The Pattern Maker creates the size by size variation of a textile item using computer software, based on a basic pattern. Write technical sheets for the preparation of prototypes and industrialization Create patterns based on indications from stylists or model makers Respect manufacturing standards, standardization of sizes, morphological adjustments Monitor technical, economic and environmental imperatives

## Related Job Titles

- CAD pattern maker
- Patternmaker-grader
- Pattern maker-grader in the clothing industry and other fabric-based manufacturing
- Pattern maker-grader / Pattern maker-grader in the soft materials industry
- Pattern maker-grader / Pattern maker-grader knit

## Activities and Skills

- Adapt a pattern or template from the sketch
- Analyze model specifications for pattern creation
- Design and develop a model, a prototype
- Design a pattern
- Start printing and cutting a pattern
- Manually make a template, a pattern
- Design a technical sheet or file with a view to industrializing a model
- Create technical documentation
- Decline the sizes of a base model on grading software
- Make adjustments to a path
- Create a computerized placement/cutting diagram for the pattern pieces
- Use CAD software for pattern modeling
- Use data management software
- Detect assembly difficulties, non-conformities (aesthetics, falling clothing, fit) and provide technical solutions
- Manually carry out a size by size gradation by transferring proportional values (compass, etc.)
- Control the outline of a pattern on the screen
- Check the conformity of the basic pattern of the article
- Identify the constituent parts of the item by marking and record additional information (assembly notches, front, back, etc.) on the pattern
- Clearly communicate cutting instructions to operators
- Report your action, risks or anomalies to the manager
- Classify patterns and technical documents for the products produced
- Respect the rules of Quality, Hygiene, Safety, Health and Environment (QHSSE)
