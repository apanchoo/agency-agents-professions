# Information system application manager

## Scope

The Information System Application Manager plays a role in the management and optimization of a company's IT systems. Ensures the maintenance and evolution of applications to meet user needs Manages updates and security patches to ensure the reliability and security of systems Collaborates with development teams on system performance to integrate new features Provides technical support and trains users on applications and their improvement Participates in the planning and implementation of new IT projects Diagnoses application incidents
