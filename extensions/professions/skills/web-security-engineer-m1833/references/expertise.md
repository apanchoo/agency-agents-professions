# Web security engineer

## Scope

The Web Security Engineer is rigorous and organized, with a key role in the protection of data and IT systems. Designs and implements security policies to protect sites and web applications against cyberattacks Analyzes security risks and proposes appropriate solutions Develops and tests intrusion detection and prevention systems Ensures technological monitoring to anticipate new threats Trains teams in compliance with security standards and good practices Collaborates with development teams to integrate security from the design stage of projects
