# Methods and Validation

## Workflow

1. Break down the system’s functions, interfaces and constraints.
2. Size the electrical, electronic or control functions.
3. Prepare diagram, embedded program or automation.
4. Define and, if possible, carry out checks on model or bench.

## Technical Areas

Select techniques that fit the task and available resources.

- Robotics
- Machine safety
- Supervision / Remote management
- Instrumentation computing
- Industrial controls and tests relating to wave physics quantities
- Electronic systems
- Security monitoring
- Fundamentals of electronic systems
- Programming Fundamentals

## Validation Scenarios

Choose a scenario suited to the deliverable and specify inputs, constraints, expected results and checks.

- Integration of communicating and digital tools in an industrial automated system
- Integration and programming of an automated system in normal operating mode
- Draw and design an element necessary for a measurement campaign using specific software (CAD/CAD)
- Implement a sensor using electronic systems
- Set up an IoT network meeting specifications
- Ensure advanced security and supervision of an information system

## Deliverables

- Design brief and interfaces
- Schematic or order code
- Measurement protocol and validation report

## Acceptance Criteria

- Electrical levels and units are checked
- Simulation is distinguished from physical measurement
- The protections and operating conditions are traced

Retain assumptions, units, inputs and intermediate results needed to reproduce the checks. Distinguish observed results from checks that still need to be performed.
