# MIG MAG Welder

## Scope

The MIG MAG welder uses gas shielded arc welding processes with fusible wire to join metal parts. The MIG (Metal Inert Gas) process uses an inert gas like argon, while the MAG (Metal Active Gas) process uses an active gas like carbon dioxide or argon mixed with carbon dioxide; These techniques are commonly used to weld metals like steel, aluminum and alloys. Selects, cuts and adjusts metal parts to be welded Configures MIG and MAG welding station parameters according to project specifications Makes precise welds on metal parts using MIG (Metal Inert Gas) and MAG (Metal Active Gas) processes Verifies the quality of welds using visual tests and measuring instruments Interprets technical plans and drawings to produce welds that meet specifications
