# Mobile network installation installer

## Scope

The Mobile Network Installation Assembler installs and configures telecommunications equipment on different sites. Carry out the installation of antennas, pylons and transmission equipment for mobile networks Carry out operational tests and diagnostics Carry out preventive and corrective maintenance of telecommunications equipment
