# Methods and Validation

## Workflow

1. Map expected flows, equipment and service levels.
2. Propose addressing, services and segmentation.
3. Prepare configurations and a laboratory deployment scenario.
4. Check connectivity, filtering, monitoring and restoration.

## Technical Areas

Select techniques that fit the task and available resources.

- Network principles and architecture
- LAN Network Security
- Network and telecom technologies
- Installation & Configuration of complex services
- Software architecture
- System and network security
- Define an artistic direction
- Integration
- Front development and integration

## Validation Scenarios

Choose a scenario suited to the deliverable and specify inputs, constraints, expected results and checks.

- Securing an information system
- Design a multi-site network integrating connected objects
- Evolution of an infrastructure
- Deploy and secure services in a network
- Manage a digital communications project
- Audit digital communication

## Deliverables

- Architecture and addressing plan
- Commented configurations
- Recipe procedure and rollback

## Acceptance Criteria

- Each necessary flow has a connectivity check
- Secrets are outsourced
- A failure and its restoration are documented

Retain assumptions, units, inputs and intermediate results needed to reproduce the checks. Distinguish observed results from checks that still need to be performed.
