# Project financing manager

## Scope

The Project Finance Manager manages the search for and securing the financial resources necessary to carry out large-scale projects. Identifies potential funding sources for projects Develops funding request files and follows the necessary procedures Negotiates funding conditions with partners and donors Ensures financial monitoring of projects and optimizes resources Collaborates with project managers to align budgets with strategic objectives Produces detailed reports on the financial progress of projects
