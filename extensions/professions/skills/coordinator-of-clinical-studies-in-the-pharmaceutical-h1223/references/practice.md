# Methods and Validation

## Workflow

1. Define question, population and dictionary of variables.
2. Control missing data, duplicates, units and bias.
3. Choose a descriptive analysis or a suitable model and validation.
4. Present results with uncertainty and reproducibility.

## Technical Areas

Select techniques that fit the task and available resources.

- Communication of information and documentary research
- Software development
- Data communication, ethics and responsibility
- Industrial controls and tests relating to wave physics quantities
- Algorithmics and computing
- Instrumentation computing

## Validation Scenarios

Choose a scenario suited to the deliverable and specify inputs, constraints, expected results and checks.

- Regulatory compliance to analyze data
- Regulatory compliance to process data
- Implement computer instrumentation techniques for monitoring measurements
- Conduct a test campaign with measurements and analyzes in the time domain and in the frequency domain

## Deliverables

- Prepared game and dictionary
- Analysis or reproducible model
- Visualization and interpretation note

## Acceptance Criteria

- No leak between learning and evaluation
- Collection and inference limits are indicated
- Each result is linked to data and a method

Retain assumptions, units, inputs and intermediate results needed to reproduce the checks. Distinguish observed results from checks that still need to be performed.
