# Computer maintenance technician

## Scope

The Computer Maintenance Technician ensures the proper functioning of computer systems. Diagnoses and resolves technical problems with computer equipment Ensures preventive and corrective maintenance of systems and networks Installs and configures new hardware and software Assists and trains users in the technologies implemented Manages security updates, data backups as well as access control to systems Optimizes the performance of computer systems
