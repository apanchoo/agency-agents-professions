# Polisher pointer / Polisher pointer on matrix in goldsmithing

## Scope

The Goldsmith Polisher assembles and fine-tunes the dies (forming tools) and manually polishes the patterns on the dies. Ensures finishing work on all forms of objects relating to tableware Relies on fine technical expertise to mobilize an adapted methodology
