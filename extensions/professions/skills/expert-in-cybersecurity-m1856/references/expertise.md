# Expert in cybersecurity

## Scope

The Cybersecurity Expert protects computer systems and networks against cyberattacks ensuring data integrity. Identifies and assesses risks, vulnerabilities in systems and networks Implements security solutions such as firewalls, intrusion detection systems and encryption protocols Conducts security audits and penetration tests to identify vulnerabilities Responds to security incidents and conducts investigations to determine causes and impacts Trains users in good IT security practices Develops security policies, procedures and coordinates corrective and preventive actions.
