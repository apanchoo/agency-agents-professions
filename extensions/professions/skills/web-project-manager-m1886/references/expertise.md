# Web Project Manager

## Scope

The Web Project Manager is responsible for managing the company's internet and intranet projects. Coordinates the development of websites and mobile applications in collaboration with technical, functional and creative teams Defines client needs and develops functional and technical specifications Ensures project monitoring, compliance with deadlines, management of the budget and the quality of deliverables Optimizes the user experience (UX) and the user interface (UI) based on user feedback and new trends Manages communication between the different stakeholders of the project, including clients, developers, designers and marketers Analyze the performance of the sites and applications developed and propose continuous improvements Plays a role in the digitalization of the marketing strategy in terms of the creation of a website or a digital communication campaign
