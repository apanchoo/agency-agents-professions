# IT project manager

## Scope

The IT project management project manager orchestrates the development of IT solutions adapted to customer needs. Defines the client's needs and develops the technical specifications Coordinates and plans the project in collaboration with the technical teams and clients Supervises the development, integration and implementation of IT solutions Ensures monitoring of the project, compliance with deadlines, budget and quality of deliverables Organizes and leads monitoring and coordination meetings with the various stakeholders Produces the reporting and technical documentation necessary for the project
