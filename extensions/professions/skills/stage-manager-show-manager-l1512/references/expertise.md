# Stage manager / Show manager

## Scope

The show manager supervises and coordinates the technical production of shows and events in accordance with the expectations of artistic management. Coordinates all technical and logistical aspects of a show or event Ensures the management and optimization of budgets allocated to productions Supervises the technical teams and ensures liaison between the different stakeholders Plans and controls compliance with deadlines for each phase of the project Ensures compliance with safety standards and regulations in force

## Related Job Titles

- Live show technical director
- Stage manager / Show production manager
- Room manager
- Choir manager
- Orchestra manager
- General manager
- General manager / General show manager
- Responsible for show logistics
