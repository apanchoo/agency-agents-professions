# Business software integrator

## Scope

The Business Software Integrator is responsible for installing and configuring the software package, adapting it to the customer's requirements. Contributes to the drafting and revision of the specifications Analyzes the risks of the project, the feasibility of the specifications, the need expressed in the functional specifications and the configuration file Carries out the tests associated with the configuration and adapts them to customer requirements Installs the new modules of the software package as well as the requested developments Writes technical support useful to the product maintenance teams.
