# Web designer

## Scope

The Web designer designs and creates the ergonomic visual interface of a website or application. Designs a graphic proposal in accordance with the client's needs Defines and declines the visual identity on all media while respecting the graphic charter Carry out simple integrations on all media (graphics, animations) Optimizes navigation and information architecture on digital platforms Adapts designs to different communication media (responsive design, etc.)
