# Software or application developer

## Scope

The software or application developer, architect of the digital world, shapes the IT solutions of tomorrow. Designs and develops computer applications according to user needs Writes source code using various programming languages ​​Tests and debugs applications to ensure their reliability and effectiveness Collaborates with multidisciplinary teams to integrate new features Documents development procedures to facilitate maintenance and updates Ensures technology monitoring to stay at the forefront of software innovations

- Computer scientist / Applications computer scientist
- Programmer / Application programmer
