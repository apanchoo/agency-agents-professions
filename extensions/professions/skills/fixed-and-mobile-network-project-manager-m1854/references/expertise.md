# Fixed and mobile network project manager

## Scope

The Fixed and Mobile Network Project Manager manages the design, deployment and evolution of network solutions and architectures. Analyzes technical and functional needs to define appropriate network solutions Designs, develops and optimizes architectures, technical solutions for telecommunications networks Plans and organizes the different phases of the project, ensuring compliance with deadlines, costs and quality Supervises the implementation, controls compliance, security and performance of the deployed solutions Leads and coordinates internal and external teams, while managing relationships with customers and partners
